## 5. Phase 4 — Skewed Workloads and Dynamic Chunk Queue

The experiment processed 8,000 items across 16 workers. The workload increased with the item index according to:

`K(i) = 1 + floor((i / 40)^2)`

Three scheduling strategies were evaluated: contiguous block static scheduling, cyclic round-robin static scheduling, and dynamic scheduling with different chunk sizes.

### 5.1 Static scheduling

| Strategy | Wall time (s) | Load imbalance λ |
|---|---:|---:|
| Contiguous block static | 3.0570 | 2.4616 |
| Cyclic round-robin static | 2.1180 | 1.0208 |

Contiguous block scheduling produced a high load imbalance because later items required substantially more computation than earlier items. Workers assigned the later ranges had much more work.

Cyclic scheduling distributed items with different computational costs among workers. As a result, worker active times became much more balanced, with an imbalance factor of 1.0208.

### 5.2 Dynamic scheduling

| Chunk size | Wall time (s) | Load imbalance λ |
|---:|---:|---:|
| 1 | 1.9592 | 1.0500 |
| 8 | 2.0032 | 1.0439 |
| 64 | 2.1208 | 1.1266 |
| 512 | 2.8057 | 2.3266 |

The best dynamic scheduling result was obtained with chunk size 1. It achieved the lowest wall time of 1.9592 seconds.
### Best result

- Best dynamic chunk size: 1
- Best dynamic wall time: 1.9592 seconds
- Best dynamic imbalance factor: 1.0500
- Block static wall time: 3.0570 seconds

Dynamic scheduling with chunk size 1 was approximately 35.9% faster than contiguous block static scheduling.
